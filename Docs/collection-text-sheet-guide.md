# 도감 텍스트 시트 안내 (기획 담당용)

도감 화면의 설명 문구는 구글 시트에서 고치고, 개발 쪽에서 CSV로 받아 게임에 넣습니다. 아래 양식을 지켜 주시면 그대로 반영됩니다.

## 탭 두 개

시트에는 탭이 두 개 있습니다. 탭 이름은 바꿔도 되지만, **첫 행(헤더)의 글자는 그대로** 두어야 합니다.

**`collection_eras` (시대 3행)**

| id | 시대 이름(참고) | 건물 이름(참고) | 기간 문구 | 시대 설명 | 비고 |
| --- | --- | --- | --- | --- | --- |
| samguk | 삼국 | 석굴암 | 고구려 · 백제 · 신라 | … | |
| goryeo | 고려 | 경천사지 십층석탑 | 고려 | … | |
| joseon | 조선 | 경복궁 | 조선 | … | |

**`collection_relics` (유물 9행)**

| id | 시대(참고) | 유물 이름(참고) | 도깨비 기본 이름(참고) | 유물 설명 | 복원 기록 | 비고 |
| --- | --- | --- | --- | --- | --- | --- |

| … | | | | | | |

## 고쳐도 되는 칸

- **기간 문구, 시대 설명, 유물 설명, 복원 기록**만 게임에 들어갑니다. 비워 두면 반영이 거절되니 꼭 채워 주세요.
- 셀 안에서 줄을 바꾸면(Mac: ⌘+Enter, Windows: Ctrl+Enter) 화면에서도 줄이 바뀝니다. 쉼표·따옴표도 그대로 써도 됩니다.
- **비고** 열은 메모용입니다. 게임에 들어가지 않습니다.

## 고치지 않는 칸

- **id** 열은 게임이 유물을 찾는 열쇠입니다. 바꾸거나 지우거나 행을 복사해 두 번 넣으면 반영이 거절됩니다. 시트 보호(데이터 → 시트 및 범위 보호)로 이 열을 잠가 두는 것을 권합니다.
- 이름에 **(참고)**가 붙은 열은 서버에 등록된 이름을 보여 주는 칸입니다. 여기를 고쳐도 게임 속 이름은 바뀌지 않고, 개발 쪽에 "이름이 다르다"는 경고만 뜹니다. 이름을 바꾸고 싶으면 개발 팀에 따로 알려 주세요.
- 헤더(첫 행) 글자를 바꾸면 그 열을 찾지 못해 반영이 거절됩니다. 새 열이 필요하면 `비고`를 쓰거나 개발 팀에 요청해 주세요.

## 행 순서와 빈 행

- 행 순서는 바꿔도 됩니다. 게임 속 순서는 따로 정해져 있습니다.
- 맨 아래 빈 행은 괜찮습니다. 유물 행을 지우거나 새 유물 행을 추가하면 반영이 거절됩니다(유물 추가는 서버 작업이 먼저 필요합니다).

## 고친 뒤 넘기는 방법

1. 탭마다 **파일 → 다운로드 → 쉼표로 구분된 값(.csv, 현재 시트)**을 누릅니다.
2. 받은 파일 두 개를 개발 담당에게 전달하거나, "시트 고쳤어요"라고 알려 주세요. 개발 쪽에서 내려받아 반영합니다.
3. 반영 결과에 오류가 있으면 몇 번째 행의 어느 칸인지 알려 드립니다. 행 번호는 시트 왼쪽의 행 번호와 같습니다.
