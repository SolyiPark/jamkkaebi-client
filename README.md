# Jamkkaebi

## Mobile 2D UI prototype

`Mobile2DUIPrototype/`는 독립된 Unity 프로젝트입니다. 루트의 게임 프로젝트와 각각 따로 엽니다.

1. Git LFS를 설치하고 `git lfs pull`로 이미지 파일을 받습니다.
2. Unity Hub에서 `Mobile2DUIPrototype` 폴더를 프로젝트로 추가합니다.
3. Unity **6000.3.14f1**로 열고 `Assets/Scenes/UIPrototype.unity`에서 Play를 실행합니다.

실행 방법과 UI 구조는 [프로토타입 README](Mobile2DUIPrototype/README.md)를 참고하세요.
루트 게임 프로젝트의 Unity 버전과 패키지 설정은 별도로 유지됩니다.
